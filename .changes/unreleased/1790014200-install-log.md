---
type: Changed
title: The install step shows a running log of files instead of one truncated line
---

While files were downloading, the install step showed three destinations on a single truncated line — enough to prove something was happening, not enough to see what. It is now a ten-line terminal-style panel: what has landed, newest at the bottom, with its size (or "unchanged" for a file a previous install already had), the files in flight underneath, and failures marked in red. It follows the tail as new lines arrive and stops following the moment you scroll up to read something.
