---
type: Changed
title: The install folder is shown by its full path, and the desktop app defaults to ~/nquake
---

The folder and review steps showed only the folder's own name, so an install into `~/nquake` and one into `~/games/old/nquake` both read as "nquake". Where the surface knows the whole path — the desktop app — the whole path is shown, with the `nQuake` subfolder appended when one is going to be created. A browser genuinely does not know it: the File System Access API hands the page a handle carrying nothing but a name, so there the name is still all there is to show.

The desktop app also no longer starts with no folder at all: it arrives at the folder step with `~/nquake` already chosen (created only when the install actually writes into it), so Next works straight away, and its folder dialog opens in your home directory.
