---
type: Changed
title: A text size button replaces pinch-zoom on phones
---

The page no longer zooms on a phone: a pinch could scale the sticky Next bar off the screen, or leave the field you were meant to answer outside the viewport, and the wizard has no horizontal scroll to find it again with. The zoom that was doing a real job — making the type readable — is now a button in the header, next to the theme toggle: small, medium (the default, and what every install so far has looked like) and large, cycling in that order and remembered per browser like the theme is. It moves the root font size, so the whole layout grows with the text rather than the text alone outgrowing its boxes. `?text=large` picks a size for one page load, and `scripts/screenshots.mjs --text large` photographs the wizard at it.
