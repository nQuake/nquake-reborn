---
type: Added
title: The install log shows every file as it downloads
---

Each file in flight now has a spinner, a percentage, its bytes so far and a fill behind its row, so the log shows what is downloading as well as what has landed. When the downloads finish, the log says what the installer is doing next (packing configs into `configs.pk3`, writing the install record and readme), and each packed archive appears in the log like any other file.
